# By & Heart

A single-page memorization companion. Paste any text — English or Arabic — and walk through six stages of active recall:

1. **Read** — slow, intentional first pass
2. **Chunk** — one sentence at a time
3. **Cloze** — fill in random blanks, three tries each
4. **First Letters** — actor's prompt technique
5. **Fade** — slider-controlled opacity
6. **Recite** — type from memory, see word-level diff

Arabic content is auto-detected: panels flip RTL, fonts swap to Amiri + Noto Naskh Arabic, sentence splitter handles `؟` and `۔`, matching ignores tashkeel diacritics and canonicalizes alef / ya / hamza / ta-marbuta variants.

No backend. No tracking. Everything runs client-side. Best score per text is cached in `localStorage`.
